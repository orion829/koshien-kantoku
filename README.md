# 甲子園監督

一款以日本高中棒球為題材的 roguelike 網頁遊戲。你是一位六月底空降的新任監督，
必須在三個夏天之內，帶領一所無名高校從地方大賽一路打到甲子園冠軍。

純靜態網頁，無任何相依套件與建置步驟。

## 本機執行

ES modules 需要透過 HTTP 提供，不能直接用 `file://` 開啟。

```bash
python -m http.server 8080
```

然後開啟 http://localhost:8080

## 部署到 GitHub Pages

專案根目錄就是網站根目錄，不需要建置：

1. 推上 GitHub
2. Settings → Pages → Source 選 `Deploy from a branch`
3. Branch 選 `main` / 資料夾選 `/ (root)`

`.nojekyll` 已包含，避免 Jekyll 處理靜態檔案。

## 設計規格

### 時間軸

以「週」為單位。一個標準年度為 `27 + 必要勝利数` 週：

| 階段 | 週數 |
|---|---|
| 新学期・新入部 | 3 |
| 練習試合期 | 3 |
| 予選直前調整 | 2 |
| 地方大会 | 5〜8（依都道府県） |
| 甲子園 | 5 |
| 世代交代 | 2 |
| 秋季県大会 | 3 |
| 冬期・スカウト | 6 |
| センバツ | 3 |

一局（run）為三個夏天：第1年從六月就任開始（省略春季6週），
第3年在夏季甲子園決勝結束。總長度 **76〜85 週**，依所選都道府県而異。

### 難度

必要勝利数 `ceil(log2(參加隊伍數))`，範圍 5〜8 勝：

| 勝數 | 分級 | 地區數 |
|---|---|---|
| 5 | 過疎県 | 5 |
| 6 | 中堅県 | 27 |
| 7 | 強豪県 | 10 |
| 8 | 激戦区 | 7 |

最易為鳥取（21隊／5勝），最難為愛知（174隊／8勝）。
參加隊伍數越多，招生池品質越高——時間成本與人才供給互相抵銷。

### 敗退週的處理

賽程中標記為 conditional 的週次，在敗退後轉為育成週。訓練效率隨
「距離上一場正式比賽的週數」遞減（1–4週 ×1.0、5–8週 ×0.75、9週以後 ×0.5），
`練習試合` 可將計數器往回撥 4 週。實質兌換率約 0.8。
